# RAVUNIX 👻
3D horror escape game (Three.js, single player, PC + mobile). Basement se shuru karo, fuse dhundo, generator chalao, chaabiyan jama karo, chhat se pipe pakad ke bhaag jao.

Play: GitHub Pages (Settings → Pages → Deploy from branch → main / root).
Local: `python3 -m http.server` phir http://localhost:8000

Controls: WASD, Shift sneak, Ctrl ya W-W / R sprint, Space jump, E inventory, F torch, LMB attack/todo, RMB use, 1-9 hotbar, Q drop. Mobile: joystick + touch buttons.
